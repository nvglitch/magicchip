## 来源与疑点

十份已处理资料是 SR 文件夹中的 MC30S、MC30W、MCSR6N1、MCSR6N2、MCSR6N3、MCSRP7、MGSRN100，以及 NAS 主板文件夹中的 NASD2700、NASN100、NASN150；准确相对路径、文件大小、日期和 SHA-256 保存在来源清单，各产品的数据和 CMS 也保留来源路径与 SHA-256。

- MCSR6N2 的 CPU 行为 13 代/U300，而平台名称为 Alder Lake-U；HDMI 1.4 同时标称 4K@60Hz，来源内部需复核。网页省略有冲突的平台命名及显示版本/分辨率，保留已确认 CPU 型号、HDMI/DP/Type-C、DDR4、网络、存储、供电等信息；该册 `appliedSha256` 继续为空，不伪装成完全同步。
- MC30S / MC30W 的通用旧 GPU 名称不适用于全部所列 CPU，网页采用“Intel 集成显卡，具体 GPU 随 CPU”表达，不承诺未确认的 GPU 型号。
- NASD2700 的最高内存保留所选 CPU 与合格 DIMM 的条件；不把最大容量写成标配。Xeon D-2712T 的 CPU 级最大内存可交叉核对 [Intel 规格](https://www.intel.com/content/www/us/en/products/sku/226233/intel-xeon-d2712t-processor-15m-cache-up-to-3-00-ghz/specifications.html)。
- NASJ4125 内存行写 DDR5，与 [Intel J4125 的 DDR4/LPDDR4 规格](https://www.intel.com/content/www/us/en/products/sku/197305/intel-celeron-processor-j4125-4m-cache-up-to-2-70-ghz/specifications.html)不符；按用户指示暂不处理，未上架。
- MCSR6N4 的内存速率“4800/5200/00MHz”及前 I/O 与概述中的显示版本不一致；按用户指示暂不上架，未生成产品数据、图片或新路由。
