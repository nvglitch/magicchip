# 参数搜索

本次将现有搜索扩展为基于产品参数的本地检索，不需要第三方服务或 API Key。顶部、手机端和完整结果页共用同一匹配逻辑，结果仍链接到具体型号详情。

## 支持的查询

| 示例 | 行为 |
| --- | --- |
| `9-36V`、`9～36 V`、`9V-36V`、`9 to 36V` | 查找供电参数覆盖完整 9～36V 区间的产品；12～36V 或固定 19V 不匹配 |
| `wide voltage` | 匹配明确标注宽电压，或低压输入范围上限不超过 60V 且上下限比值至少为 2 的产品 |
| `Intel`、`I want an Intel processor` | 查询处理器参数；单独使用 Intel 网卡不构成 CPU 匹配 |
| `AMD`、`Ryzen`、`DDR5`、`USB4`、`2.5GbE` | 检索相应参数或关键词；统一常见单位和空格写法 |
| `Intel 9-36V` | 所有条件同时成立 |
| 完整型号 | 原型号详情排在最前；型号前缀仍可检索 |

英文普通词支持有限的单字符拼写容错，型号和数字参数不使用这种容错。未实现任意自然语言推理、否定条件、OR 条件或“至少 32GB”这类容量比较；未知需求不会自动放宽为不满足条件的产品。

## 展示与数据

- 顶部预览前 6 条，显示命中的参数原文，并显示全部结果数量。完整结果页显示所有匹配产品。
- 113 款产品均有参数索引。工业、软路由、商用及 AI 产品读取现有目录参数；MCAIPC1、MC15UH、MCTAR7 读取现有内容 JSON。
- 产品选配项按参数表检索；结果中的参数原文保留系列和选配说明，实际配置以对应详情为准。
- CPU 平台名称 Alder Lake / Twin Lake 在搜索中识别为 Intel，处理册子省略品牌名称的情况。
- 新增产品时仍需接入现有站内搜索索引及产品目录；不自动扫描 public 文件夹。

## 维护与验证

- `lib/site-search.ts`：搜索条目及参数接入。
- `lib/search-matching.ts`：单位规范、常见需求词、电压范围、CPU 品牌和相关性排序。
- `components/SiteSearch.tsx`、`components/SearchResultsPage.tsx`：预览和完整结果。
- `node scripts/test-site-search.cjs`：回归检查，覆盖所有型号入口、电压边界、CPU/网卡区分、USB 数量与版本区分、组合条件及空结果。

当前数据测试结果：9-36V 为 12 款，宽电压为 20 款，Intel CPU 为 105 款。构建及桌面/手机端搜索交互检查通过。本次未推送或发布。

## 网站语言支持

搜索需求词覆盖英语、德语、法语、意大利语、西班牙语，无须切换网站语言即可检索。中文搜索别名已移除。

| English | Deutsch | Français | Italiano | Español |
| --- | --- | --- | --- | --- |
| wide voltage | weiter Spannungsbereich | large plage de tension | ampio intervallo di tensione | amplio rango de tensión |
| fanless | lüfterlos | sans ventilateur | senza ventola | sin ventilador |
| processor | Prozessor | processeur | processore | procesador |
| memory | Arbeitsspeicher | mémoire | memoria | memoria |
| storage | Datenspeicher | stockage | archiviazione | almacenamiento |

支持重音字符规范化，以及常见组合条件，例如 `Ich suche einen Intel Prozessor mit 9 bis 36V`、`Je cherche un processeur Intel avec 9 à 36V`。这是常见需求词与参数检索，不是任意自然语言翻译。型号及匹配证据保持产品原始参数文本。

词库维护位置：`lib/search-language.ts`。搜索页提示与顶部搜索示例也已覆盖五种语言。
