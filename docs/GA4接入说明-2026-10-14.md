# GA4 接入说明

本次完成本地接入和验证，未提交、推送或发布。用户已确认关闭 GA4 数据流的「增强型衡量」。

## 配置与同意控制

- 衡量 ID：`G-2SBJEQKDQZ`，位于 `lib/analytics.ts`。五种语言共用同一个数据流。
- 只在 `szmagicchip.com` 或 `www.szmagicchip.com` 上发送正式统计。localhost、127.0.0.1 和其他预览域名均不加载统计脚本，避免测试访问污染数据。
- 首次访问提供五语言的接受与拒绝按钮。未选择或拒绝时不加载 GA4，不发送本项目的统计事件。
- 必要的 localStorage 记录 `magicchip-analytics-consent` 只保存版本、选择和时间戳，接受及拒绝均保留 180 天。过期后停止统计并重新询问。存储被浏览器禁止时，选择仍在本次访问生效。
- 页尾的 Analytics settings 可随时重新选择。撤回后设置 Google 的统计禁用标志、更新同意状态、阻止后续事件，清理可访问的 `_ga` 与 `_ga_2SBJEQKDQZ` Cookie。尚未加载完脚本时，撤回也会清除排队事件。已发送的数据无法通过清理浏览器自动删除。
- 接受只开放 analytics_storage；ad_storage、ad_user_data、ad_personalization 均保持 denied。Google signals 与广告个性化配置均关闭。
- GA Cookie 设置为使用后最长 180 天，后续同意状态下的访问可以续期；同意记录的 180 天从明确选择时计算。
- 提示显示时聊天与返回顶部按钮自动上移；两种选择可见性一致，浏览内容与必要网站功能不以接受统计为条件。

## 统计事件

| 事件 | 触发条件 | 说明 |
|---|---|---|
| `page_view` | 同意后进入公开页面或切换页面/语言 | 手动发送一次，避免初始化与客户端导航重复；不因 SKU 锚点或查询参数单独重复计数 |
| `select_configuration` | 选择产品 SKU、MCAIPC2 主板或机箱 | 使用网站定义的配置 ID；不会读取用户输入 |
| `file_download` | 点击项目 PDF 的下载链接 | 记录下载意图，不证明文件最终下载成功 |
| `document_view` | 点击项目 PDF 的查看链接 | 与下载按钮分开计数 |
| `whatsapp_click` | 打开 WhatsApp 链接或聊天组件内的 WhatsApp 按钮 | 联系意图，不证明对方发送了消息 |
| `email_click` | 点击邮件链接 | 不传递 mailto 地址、body、subject 等内容 |
| `email_draft_prepared` | 询盘通过校验，生成邮件草稿 | 三处询盘表单均支持；不作为已收到询盘 |
| `chat_widget_open` | 打开右下角聊天面板 | 与真正进入 WhatsApp 分开 |

没有发送 `generate_lead`，也没有把打开邮件草稿当作邮件已经发送。GA4 后台的关键事件和报表需根据实际业务另外设置；以上事件不会由网站自动标记为成功成交或有效询盘。

## 数据范围

页面统计只包含固定公开路径和网站渲染的产品/新闻标识。产品页附带 `product_id`、`product_category`，事件附带 `site_language`；配置和文档操作使用 `configuration_id`、`configuration_type`、`document_id`，部分来源用 `source`。

不读取或上传表单姓名、邮箱、公司、留言、邮件草稿正文或网站搜索词。页面 URL 的查询参数和锚点全部排除；外部来源只保留 origin，避免引荐地址含搜索词或个人资料。没有读取浏览器 document.title，而是根据固定公开路径生成统计标题。没有向 Google 传递完整 mailto/WhatsApp 链接。

此设置也不会保留 URL 中的 UTM、广告点击参数或完整外部引荐路径；目前适合基本访问来源和产品关注分析。后续要做广告归因，应另行设计允许传递的广告参数与同意机制。

五语言 Cookie 与隐私政策同步描述 Google Analytics、同意依据、180 天偏好记录、Cookie 续期、撤回方式、数据范围及处理方。政策没有虚构 Google 账号后台的数据保存期限；应按实际后台配置维护。

## 上线后验证

1. 按原流程自行提交并部署。没有新增环境变量要求，ID 已在代码里配置。
2. 打开正式域名，使用一个尚未选择统计的浏览器窗口。先拒绝：应没有 GA4 脚本加载。再从页尾设置接受，GA4 才开始运行。
3. 打开 GA4 实时报告，浏览首页、产品页，选择一次 SKU，点击证书下载。应能看到相关页面及对应事件。客户端导航、切换语言或刷新，每次真实页面进入应只有一次 `page_view`。
4. 撤回同意后继续浏览，不应再新增本项目的统计事件。浏览器广告拦截、网络阻断或未同意会影响是否收到统计。
5. 在 GA4「自定义定义」中按需建立事件范围维度，例如 `site_language`、`product_id`、`product_category`、`configuration_id`、`document_id`，用于按语言、产品和资料做探索。

保持「增强型衡量」关闭，避免自动历史页面浏览与手动页面统计重复，也避免自动链接、搜索或表单采集绕过本项目的数据筛选。不要再把同一个 ID 通过 GTM 或另一个组件重复安装。

本次未访问 GA4 后台或正式上线网站，不声称已经验证 Google 账号中的实时数据。最终接收情况需在部署后验证。
